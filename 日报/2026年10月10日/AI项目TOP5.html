🥇CC Switch — 一个桌面窗口，管住你所有 AI 编程工具的供应商与配置⭐ 141,902

现在同时用 Claude Code、Codex、Gemini CLI、Hermes 的人，痛点都一样：每换一家 API 供应商就要手改 JSON / TOML / YAML / .env，MCP、技能、提示词还得在每个工具里各维护一份。CC Switch 把这些收进一个桌面应用：选中工具 → 挑预设 → 填 Key → 一键切换，而切换只替换端点、Key、模型这类连接信息，你加的插件、hooks、MCP 和注释原样保留；首次启动会自动把现有配置导入成一个叫 default 的供应商，不会丢东西。三种接法随你挑——直连（工具直接连供应商）、路由（请求经本机转发，自动做 API 格式转换与故障转移，于是能在 Claude Code 里用 GPT、在 Codex 里用 Claude）、聚合（把多家供应商的模型合并成一个模型列表，选哪个模型就走哪家）。除了供应商，它还把 MCP 服务器、技能（可从 skills.sh 或 GitHub 一键安装并同步到各工具）、提示词（写入 CLAUDE.md / AGENTS.md / GEMINI.md，原内容先存回库）、会话阅读视图（每一轮干了什么、改了哪些文件、哪一步失败，一眼看清，还能复制恢复命令接着聊）和用量额度（官方订阅的 5 小时 / 周 / 月配额、账户余额，直接显示在供应商卡片和托盘上）统一管起来。

用途：手上有多家模型通道或订阅的人，用它统一管理、一键切换，还能在 Claude Code 里跑 GPT、在 Codex 里跑 Claude，不用再手改配置文件 · 亮点：10 月 7 日发布 v4.0 正式版——界面、聚合模式、配置切换全面重做，是该项目迄今最大的一次更新，随后 10 月 8 日 v4.0.5、10 月 9 日 v4.0.6 连发修复（Codex 可以用 GitHub Copilot 账号、供应商页新增搜索、Skills 检查到更新后一键全量更新、额度不足 20% 三色提醒、修复 Claude Code 经路由转 OpenAI 格式时最后一段回复丢失等）；内置 90+ 供应商预设，Windows / macOS / Linux 原生桌面（Tauri 2，macOS 版已签名公证，brew install --cask cc-switch 即可装） · 适合：同时用多个编程 Agent 或多家模型通道、不想再手改配置文件的开发者

5️⃣MemPalace — 让 AI 记住你：本地存原文、按语义找回，全程不调云端⭐ 59,486
MemPalace/mempalace

一个「本地优先」的 AI 长期记忆系统。它不做摘要、不做改写，把对话原文逐字存下来，再用语义检索找回去；索引是结构化的——人和项目分成 wing、话题分成 room、原文放在 drawer，所以搜索可以限定范围，而不是在一片平铺的语料里瞎捞。用法很直接：mempalace mine ~/projects/myapp 把项目文件挖进记忆宫殿，mempalace mine ~/.claude/projects/ --mode convos 把 Claude Code 的历史会话也挖进去，mempalace search "我们当时为什么换成 GraphQL" 检索，mempalace wake-up 在新会话里一次性加载上下文，mempalace audit 给记忆宫殿的整理度打分。它还带一个有时间有效期的实体关系知识图谱（本地 SQLite）、45 个 MCP 工具（读写、图谱、跨 wing 导航、Agent 日记与协作）、以及给 Claude Code / Codex CLI / Cursor 用的自动保存钩子（定期保存，并在上下文压缩前抢救一轮）。安装推荐 uv tool install mempalace（隔离环境，避免和系统 Python 打架），也支持 pipx 与 Docker。

用途：治 Agent 最大的短板——换个会话就忘光。把项目历史、决策原因、个人偏好存成可检索的长期记忆，新会话一句 wake-up 就接上；也适合做跨工具共用的记忆库 · 亮点：官方基准可复现且不依赖云：LongMemEval 500 题纯语义检索 R@5 达 96.6%（全程不用 LLM、不用 API Key），混合管线在 450 题留出集上 98.4%，再加一次 LLM 重排可到 99% 以上；10 月 6 日一批性能提交把挖掘、检索、隧道同步都改成批量处理，大记忆库也能保持轻快；原文逐字存储，不是「AI 帮你总结的记忆」，不会越用越失真 · 适合：长期和 AI 结对做项目、又不想把聊天记录交给第三方的人
