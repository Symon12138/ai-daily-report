🥈Agent Reach — 给 AI Agent 一键装上「看全网」的眼睛：推特、Reddit、B站、小红书都能读⭐ 96,013

它是一层「能力层」，不是又一个爬虫工具：负责把每个平台当下最稳的接入方式替你选好、装好、体检好，真正读取的动作仍由 Agent 直接调用上游工具完成，中间没有包装层。零配置就能用的有六个渠道——读任意网页（Jina Reader）、YouTube 字幕与搜索（yt-dlp）、任意 RSS/Atom、B站搜索与视频详情、V2EX 热门帖、GitHub 公开仓库；需要登录态的推特、Reddit、Facebook、Instagram、小红书、LinkedIn、Boss直聘、雪球、小宇宙播客，只要对 Agent 说一句「帮我配 XXX」，它会一步步引导你。安装就一句话：把安装说明的链接发给 Agent。Cookie 只存在本地、不上传，`agent-reach doctor` 一条命令体检所有渠道并告诉你当前走的是哪条路。

用途：让 Agent 自己去外面取一手信息，而不是等你复制粘贴——做选题、查资料、盯竞品、看评论区都直接可用 · 亮点：每个平台都是「首选 + 备选」的有序后端列表，某个接入方式被平台封了它换下一个，用户零操作（2026 年 3 月一批单平台 CLI 集体停更、6 月 B站风控封死 yt-dlp，都是靠换路由解决的）；所有工具与 API 免费，本地电脑不需要代理；兼容 Claude Code、OpenClaw、Cursor 等任何能跑命令行的 Agent；MIT 许可、Python 3.10+ · 适合：想让 Agent 真正联网查一手信息，又不想为每个平台单独折腾登录和依赖的人
