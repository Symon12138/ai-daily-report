🥉Caveman — 让 Agent 说「原始人话」：答案不变，token 砍掉一大截⭐ 110,928
JuliusBrussee/caveman

它本质上是一种「说话方式」技能（另配一个代理）：回答先给结论，一句话只说一个意思，删掉问候、客套、「让我想想」和结尾的总结，但语义一个字都不能丢——否定词、数字、单位照旧精确，代码、命令、路径、报错信息和原有注释原样保留。同一个 React 重渲染问题，普通 Agent 的答复是 63 个 token，caveman 压到 20 个；再狠一档的 /ultracave 是 14 个，/megacave 用中文只说 13 个。除了技能，它还带 caveman browse：替 Agent 抓网页时，输出比 Playwright 快照小 129.8 倍。

用途：按 token 付费的人直接省钱；上下文窗口吃紧时，同样的额度能塞进更多内容 · 亮点：官方实测：走它的代理时输入 token 少 33.2%（54 次 Claude Code 运行、18 个问题全部答对），caveman 风格输出让整体成本降到 1.4–2.4 倍便宜；10 月 8 日发布 v3.2.0，同时上线 @caveman-ai/middleware 1.0.1，支持 30+ 种 Agent，Apache-2.0 许可 · 适合：每天大量用 Agent、账单开始肉疼的人
